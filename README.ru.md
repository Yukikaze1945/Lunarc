# Lunarc — улучшение видео и изображений с DLSS 5

<p><img src="docs/assets/lunarc-logo.svg" width="32" height="32" alt="Lunarc" /> &nbsp; <strong>LUNARC</strong></p>

![Lunarc — Улучшение видео и изображений](docs/assets/lunarc-banner.png)

**Windows x64** · **GPL-3.0-or-later**

Lunarc использует нейронный рендеринг DLSS 5 (DLSS5 / DLSSNR) для улучшения видео и изображений в Windows. Поддерживаются DLAA, масштабирование RTX VSR, интерполяция кадров NVIDIA VFG, преобразование SDR в HDR с TrueHDR и отдельные модели увеличения изображений.

[Скачать](https://github.com/Yukikaze1945/Lunarc-DLSS5/releases/latest) / [Руководство](docs/ru/user-guide.md) / [Сайт](https://lunarc-workbench.defaddg-9590.chatgpt.site/ru/)

Страница описывает текущие исходники. Возможности конкретного установщика указаны в описании выпуска. Переключение языка входит в это обновление исходников; в старых установщиках оно автоматически не появляется.

## 02 / Возможности

| Функция | Что доступно |
| --- | --- |
| DLSSNR | Один, два или три слоя с отдельными настройками. Последовательная обработка или экспериментальное многомасштабное согласованное слияние. |
| DLAA | Пресеты модели; поддержка зависит от установленной библиотеки. |
| RTX VSR | Несколько этапов с изменяемым порядком, уровни качества и сила эффекта, увеличение по масштабу или разрешению. Режимы зависят от GPU и библиотеки. |
| Оптический поток | NVIDIA NVOF, AMD FidelityFX Optical Flow, RAFT-Large. Размер анализа и итерации RAFT настраиваются. |
| NVIDIA VFG | Фиксированный множитель или целевой fps, обнаружение смены сцен. Только экспорт; 5×–8× экспериментальны. |
| Цвет и TrueHDR | SDR 8/10 бит и экспериментальный HDR10. Контраст, насыщенность, средний серый, пиковая яркость и ИИ-устранение полос TrueHDR. Нужны внешние компоненты NVIDIA. |
| Изображения | IllustrationJaNai V3 и AnimeSharp V4, веса устанавливаются отдельно. Экспорт PNG, JPEG, WebP, AVIF и HEIC при наличии кодировщика. Сейчас вывод изображений — SDR. |
| Пресеты и диапазоны | Сохранение/применение настроек, отличия от исходных, сворачиваемые карточки, экспорт диапазона и предрендер. Готовые совпадающие диапазоны кэша показаны зелёным. |
| Библиотеки | Загрузка/импорт версий DLSSNR, проверка хешей и подписей, выбор версии из кэша. Другие компоненты NVIDIA имеют свои требования. |

Нативный вход P010 поддерживает **HEVC Main10** и **AV1 Main, 10 бит** для SDR 10 бит и HDR10 в **MKV**. Несовместимые сочетания отклоняются без скрытой подмены. Сохранение звука, субтитров, глав, вложений и метаданных зависит от настроек и контейнера.

## 03 / Установка

1. Скачайте установщик Windows x64 из [Releases](https://github.com/Yukikaze1945/Lunarc-DLSS5/releases/latest).
2. При первом запуске установите **базовую среду выполнения** и **компоненты обработки видео**.
3. Откройте **Работа и диагностика → Среда выполнения DLSSNR**, загрузите или импортируйте библиотеку, которой вправе пользоваться, и выберите её.
4. Импортируйте файл и включите нужные этапы. См. [первые шаги](docs/ru/user-guide.md#quickstart).

Установщик не требует отдельной установки Python, Node.js или CUDA Toolkit. **RAFT и модели изображений** требуют необязательных компонентов PyTorch/CUDA и весов. Нативный поток NVIDIA/AMD, декодирование и кодирование GPU не требуют PyTorch. Совместимые компоненты сохраняются при обновлении.

### Требования и ограничения

- Windows x64, совместимые с выбранными функциями GPU NVIDIA и драйвер.
- Библиотеки эффектов NVIDIA устанавливаются отдельно и сохраняют собственные лицензии.
- Первая установка компонентов требует сети. ИИ-окружение может занимать несколько ГБ загрузки.
- Нативный предпросмотр видео Windows использует FP16/scRGB для HDR при включённом Windows HDR; иначе преобразует в SDR. Сравнение файлов использует SDR. Это не откалиброванный HDR-эталон.
- HDR10, многомасштабное слияние и VFG 5×–8× экспериментальны. Скорость зависит от оборудования, файла и настроек; работа в реальном времени не гарантируется.

## 04 / Запуск из исходников

```powershell
git clone https://github.com/Yukikaze1945/Lunarc-DLSS5.git
cd Lunarc-DLSS5
```

Подготовьте Python 3.10+, Node.js 22.18+, FFmpeg/FFprobe, Visual Studio C++ Build Tools и Windows SDK. Для нативных библиотек нужны соответствующие SDK и файлы разработки FFmpeg. Задайте `DLSS_SDK_DIR` и `FFMPEG_SDK_DIR`, соберите через `native\build_all.bat`, затем запустите **`run_gui.bat`** из корня.

Команды установки зависимостей и требования AMD описаны в [руководстве по сборке на китайском](docs/getting-started.md). Обычная DLL сверхразрешения DLSS не заменяет `nvngx_dlssnr.dll`.
