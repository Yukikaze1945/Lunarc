# 队列与页面响应优化 · 2026-10-11

## 改动

- 工作台、导出页和底部状态共用一条队列 WebSocket。连接收到初始快照后停止队列 HTTP 轮询；断线时每两秒恢复连接/状态，恢复请求不重叠，并有五秒取消期限。
- HTTP 请求期间收到的实时更新优先于旧快照。迟到的进度事件不能重新创建已删除的任务，上一任务的结束消息不能清除下一任务的运行标识。
- 隐藏的导出页暂停队列订阅和日志刷新，重新进入时立即取得共享快照，并保留导出表单及日志面板的打开状态。导出页使用 React memo 避免父页面无关更新造成重复绘制。
- 工作台的最近任务诊断从共享队列触发，移除独立的八秒轮询。重试后状态变化会重新读取诊断；过期诊断响应被忽略。
- 诊断窗口按请求次序保护结果，关闭后打开其他任务不会被旧响应覆盖。
- 安装入口支持 Windows 默认 ZIP 子文件夹解压方式，在自身及上级目录查找完整分卷，仍逐卷及整体校验 SHA-256。

同一开发机，实际 Electron 和 Python 后端，隔离用户配置，停留在工作台、没有执行渲染。统计浏览器发出的 `GET /api/queue`，连接初始阶段不计入。

| 已验收的 2.1.1 安装程序 | 10.5 秒 | 13 | 1 |
| 本轮优化源码 | 10.5 秒 | 0 | 1 |

实际队列增删使用真实后端。连续添加、删除、再次添加、再次删除通过，底部状态与列表同步。诊断窗口竞态使用受控的迟到响应测试，窗口保持第二个任务的内容。隐藏日志面板四点五秒内不发日志查询，重新进入页面后自动恢复，并保持面板打开状态。

传输单元测试覆盖共享连接、过期快照、已删除任务、结束状态、断线恢复、不重叠请求和订阅释放。安装入口另以小型真实分卷验证同目录、子目录、缺卷、截断、错误哈希及非法文件名。

没有测量 GPU 渲染吞吐或播放帧率提升；这里的数据仅说明队列请求及隐藏页面工作的减少。Performance = NOT_CHARACTERIZED。
