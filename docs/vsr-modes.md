# RTX VSR 模式

VSR 磁贴新增模式选择，并将“档位”和“效果强度”分开。档位仍使用低、中、高、极高；效果强度对应 NVIDIA SDK 的 `Strength`，可设为 0–100% 或恢复运行库默认值。

| 模式 | 档位 | SDK QualityLevel | 输出尺寸 |
| --- | --- | --- | --- |
| 标准超分辨率 | 低、中、高、极高 | 1–4 | 放大 |
| 降噪 | 低、中、高、极高 | 8–11 | 保持该磁贴输入尺寸 |
| 去模糊 | 低、中、高、极高 | 12–15 | 保持该磁贴输入尺寸 |
| 高码率超分辨率 | 低、中、高、极高 | 16–19 | 放大 |
| 流媒体超分辨率 | 中、极高 | 21、23 | 放大 |
| 双三次缩放 | 无 AI 档位 | 0 | 放大 |

Streaming 模式要求 Ampere 或更新架构；模式 5–7、20、22 是保留值，不会发送给 SDK。[NVIDIA 官方说明](https://docs.nvidia.com/maxine/vfx/latest/Filters/VideoSuperResolution.html)

## 设置行为

- 旧预设没有模式字段时使用标准超分辨率，原 1–4 档位保留。`vsr_strength=null` 不调用强度 setter，沿用 SDK 默认值。双三次模式隐藏 AI 档位与强度，切回其他模式仍保留这些设置。
- 降噪和去模糊隐藏放大控件，输出保持输入尺寸；原倍率、分辨率设置没有被覆盖，切回超分恢复。
- 预览和导出共用模式映射与尺寸规则。预设管理器显示中文模式、档位及百分比。
- 切换不改变输出尺寸时，只销毁并重建 VSR 模型，保留输入/输出交换缓冲、解码器及其他模型会话。尺寸变化时重建受影响的处理/显示资源，保留源解码器与 CUDA 上下文，重新定位并处理当前帧。
- 模型或运行库不支持所选模式时明确报错；不自动换成标准 VSR，也不改用 8-bit 或 CPU。
- SDR8 使用 RGBA8，SDR10/HDR 使用现有 RGB10A2 SDK 边界与 FP16 GPU 图片链。该 SDK 边界本来就存在 10-bit 量化；此功能不声称 SDK 内部进行 FP16 推理。

不同档位会改变处理效果、速度和显存。降噪可能抹平纹理，去模糊可能放大噪声；高码率模式适合压缩损失较少的素材。不能将 Streaming 名称理解为已经实现实时播放。

## 接口兼容

新增 `rtx_vsr_open3`，接收独立 Strength；旧 `rtx_vsr_open`、`rtx_vsr_open2` 和 ABI 1 不变，仍保留 SDK 默认 Strength。新增配置查询从 SDK getters 读取实际 QualityLevel/Strength，读不到时报告 unknown，不猜默认值。SDK 回报的模式若与请求不一致，拒绝继续处理。
