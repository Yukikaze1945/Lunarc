# Lunarc 1.1.0 Beta

本版在 1.0.0 Beta 基础上加入工作台和 GPU 流程更新。

## 更新内容

- RTX VSR 增加六种模式、独立强度设置和官方质量档位；模式选择贯穿预览、导出、输出尺寸与预设。
- 增加显存用途查看和后端故障恢复；改进预览生命周期、队列恢复及导出范围处理。
- 更新渲染流程、HDR/SDR10 导出和原生 GPU 处理路径。

## 安装与更新

下载并运行 **Lunarc-1.1.0-beta-x64-Setup.exe**。本版仍使用按需安装的运行组件；RAFT 的 PyTorch/CUDA 与模型不包含在主安装器中。

1.0.0-beta 用户可在 **关于 Lunarc → 软件更新** 中勾选“包含预发布版本”检查更新。更早的 2.x 用户需先手动安装 1.0.0-beta；本版保留原有用户设置和组件目录。

## 验证范围

RTX VSR 的 GPU 模式检查及显存用途检查记录于 `docs/validation/`。这些检查覆盖指定设备和素材，不代表多机兼容性、完整功能回归或通用性能基准。Performance = NOT_CHARACTERIZED。
