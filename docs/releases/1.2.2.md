# Lunarc 1.2.2

本版增加独立图片处理工作流，并改进模型管理和 GPU 预览资源切换。

## 更新内容

- 新增图片导入、独立图片处理与导出，支持 PNG、JPEG、WebP、AVIF、HEIC；工作台提供缩放、移动和原图对比。
- 新增 AnimeSharp V4 与 IllustrationJaNai V3 图片放大模型，可按需安装模型组件并管理模型权重。
- 图片链支持组合多层降噪、DLAA、RTX VSR 与 TrueHDR；重复添加的 VSR 层各自保留参数。
- 新增释放与恢复预览资源的控制，并改进显存紧张时的预览模型切换和资源清理。
- 保留图片透明度、按输出格式处理色彩与尺寸；高位深输入和 HDR 图片导出仍不支持。

## 安装与更新

下载并运行 **Lunarc-1.2.2-x64-Setup.exe**。PyTorch/CUDA、RAFT 与图片模型运行环境按需安装；模型权重独立下载，不包含在主安装器中。

## 验证范围

本版的图片链路、导出格式、模型组件、视野操作和预览资源管理有局部 Python、Node、前端构建及指定 NVIDIA GPU 检查记录，见 `docs/validation/2026-10-15-*.md`。这些记录不代表跨设备兼容性、所有模型排列或完整视频/HDR 回归。性能数据含首次模型加载成本，不构成稳态性能承诺。
