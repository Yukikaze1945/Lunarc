# Lunarc 1.0.0 Beta

从本版重新编号。此前 2.x 发布附件下架，仓库历史保留。

## 本版内容

- Windows 工作台统一使用原生 GPU 视频预览，支持 SDR 8-bit、SDR 10-bit 和 HDR，中央滑块直接重绘 GPU 画面。
- DLSSNR 第二、第三层可独立调节参数；支持顺序处理和实验性多尺度融合。
- TrueHDR 加入可排序渲染卡片，可调对比度、饱和度、中灰亮度、目标峰值及 AI 去色带。
- 预设管理显示相对默认值的改动；工作台可选择和保存预设，卡片及设置可折叠。
- 支持选择时间区间导出和预渲染；已完成且仍匹配当前参数的缓存区间显示绿条。
- 底栏显示显存用量、渲染链耗时和预览 FPS。处理耗时为实际调用计时，不等同于纯 GPU 计时。
- 修复预览与导出会话占用、SDR10 色彩处理及导出分辨率控制等问题。

## 安装

下载并运行 **Lunarc-1.0.0-beta-x64-Setup.exe**。首次启动安装基础运行环境和视频处理组件；RAFT 的 PyTorch/CUDA 与模型按需安装，安装包不包含这些大文件或 NVIDIA 专有模型运行库。

**原 2.x 用户需手动安装本版一次**，旧版不会把较小版本号识别为更新。安装到原目录即可，已有组件和用户设置保留。后续检查 Beta 更新需勾选“包含预发布版本”。

安装程序未做代码签名。附件 **SHA256SUMS.txt** 提供完整性校验，**INSTALL.md** 提供安装说明。

## 限制

- HDR10、多尺度数据一致性融合、TrueHDR 和 5×–8× VFG 等路径仍需按显卡、驱动和对应运行库验证。
- HDR 显示需要启用 Windows HDR；未启用时映射为 SDR。文件对比页仍使用 SDR 映射。
- 局部测试不代表多机兼容性、4K 120 fps 处理或画质基准。Performance = NOT_CHARACTERIZED。
