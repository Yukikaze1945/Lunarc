# Lunarc 1.3.0

Released 2026-10-17.

## Highlights

- Added English, Japanese, and Russian desktop translations, with a language selector and translated help, presets, and workflow controls.
- Added an optional, built-in Streamable HTTP MCP server at `127.0.0.1:18923`. It reuses Lunarc's existing backend and render queue, exposes 13 tools, is disabled by default, and accepts loopback connections only. See [MCP automation](../mcp.md).
- Added HDR image input and export workflows, including the bundled Ultra HDR and JPEG XL codec tools and their license notices.
- Improved image preview rendering, memory cleanup, export feedback, and preset synchronization.
- Expanded fixed-multiplier NVIDIA VFG to 2×–16×. Multipliers above 8× are experimental; see the [validation notes](../validation/2026-10-17-vfg-16x.md) for implementation and test scope.

## Installation

Download **Lunarc-1.3.0-x64-Setup.exe** from the [v1.3.0 release](https://github.com/Yukikaze1945/Lunarc-DLSS5/releases/tag/v1.3.0). The base runtime and optional processing components are installed separately by Lunarc.
