# 软件检查与下载更新

桌面版 **关于 Lunarc → 软件更新** 提供检查、下载、暂停与续传、校验后的安装目录入口。显示实际 Electron 应用版本；源码运行会明确标注。

1. 检查更新，可选择包含预发布版本。
2. 下载新版 Setup 及小型校验/安装说明文件。
3. 校验完成后打开安装目录，退出工作台，再运行 Setup。已经安装的运行组件继续复用。

没有自动执行安装器或应用增量更新。运行组件固定版本，不会随应用检查自动升级；组件锁变化时才要求重新安装相应组件。旧完整离线包不再发布。

## 下载与校验

发布源固定为 Yukikaze1945/Lunarc 的 GitHub Releases 公共 API，无需账户令牌。忽略草稿、纯源码发布和不完整安装资产；支持版本与预发布频道选择。

小包必须提供 `INSTALLER.json`，其 schema、components 模式、版本、Setup 大小与 SHA-256 必须和 GitHub API、`SHA256SUMS.txt` 一致。更新器仍可识别历史完整资产组，以便旧格式升级。

下载在 Electron 主进程进行，页面不能指定下载地址、输出路径或执行命令。文件先写入 `.part`，完整大小/SHA-256 校验后才改为正式名称。完整文件只在再次验证后复用；部分文件续传需要精确匹配 HTTP Content-Range，服务器返回 200 时重写文件。

检查超时 20 秒，下载 60 秒没有数据会暂停并允许重试。下载缓存位于 `userData/updates/<version>`；不会使用渲染 GPU。GitHub 连通性与请求限流仍可能影响访问。

## 验证范围

`tests/node/app_updates.test.ts` 覆盖版本、频道、资产完整性、固定来源、摘要、续传、损坏与暂停，以及小包格式声明。桌面验收使用真实 Electron/preload/IPC 和微型模拟 GitHub 资产，不能描述为真实安装器联网下载。

新安装版的实际构建、组件下载、隔离启动和原生预览证据见 [公开版本验证记录](public-release.md)。
