# 软件更新

桌面版的 **关于 Lunarc → 软件更新** 显示 Electron 实际版本，提供检查更新、下载、暂停与续传，以及校验后的安装目录入口。源码运行会显示“源码运行”；浏览器页面不提供桌面下载功能。

## 使用

1. 点击“检查更新”。目前版本属于预发布，默认勾选“包含预发布版本”；该选择保存在本机。
2. 下载更新。当前安装格式会一并下载入口 ZIP、全部数据卷和发布页提供的校验/安装说明。下载期间可继续使用工作台。
3. 校验完成后打开安装目录，解压 Installer.zip。完成或移除需要保留的导出队列任务，退出工作台，再运行 Install-Lunarc.cmd。

更新不会自动退出应用、启动安装器或替换正在使用的文件。此版本提供完整安装包下载，没有增量更新；新的完整安装包仍包含独立运行环境。已经发布/正在上传的 2.1.1 安装包没有这个新入口，后续构建才会包含它。

## 实现范围

- 发布源固定为 Yukikaze1945/Lunarc 的 GitHub Releases 公共 API，不使用账户令牌。忽略草稿或缺少 SHA-256 的安装资产，检查已校验的 SHA256SUMS.txt 是否声明了漏上传的卷；按语义版本排序并允许选择预发布频道。纯源码发布不提示下载安装。
- 下载发生在 Electron 主进程，renderer 无权指定下载地址、输出路径或执行命令。IPC 限制为主窗口的主 frame。
- 仅接受官方仓库路径中的完整 x64 安装资产组。每个文件大小和 SHA-256 必须符合 GitHub API 的资产声明。校验保证文件与发布资产一致，不等同于第三方代码审计或安装器代码签名。
- 缓存位于现有 userData 的 `updates/<version>` 子目录，与模型运行库缓存分开。分卷先保存 `.part`，完整校验后才改为正式名称。校验失败的临时卷删除，已通过的卷复用。
- 续传要求 HTTP 206 的 Content-Range 精确匹配；服务器忽略 Range 返回 200 时从头重写该卷。读取超时、网络失败和暂停均可重试。每次只允许一个检查/下载操作。
- 检查超时 20 秒；下载无数据 60 秒时暂停。进度事件节流，检查与下载均不使用预览/渲染 GPU。
- 未检测到完整安装包时明确说明没有可用安装更新，不把源码 main 更新当作安装版更新。GitHub 连通性/限流仍可能影响访问。

## 验证

`tests/node/app_updates.test.ts` 覆盖版本/频道选择、草稿与不完整资产、官方 URL、大小/摘要校验、损坏数据、续传范围、暂停和重复请求。

`tests/helpers/app_updates_ui_probe.cjs <fresh-evidence-directory>` 使用真实 Electron、preload、IPC 和文件写入，以微型模拟 GitHub 资产检查按钮、完整下载与频道切换。不执行模拟安装器，也不重复下载 2.5 GB 真实安装包。

2026-10-12 验证：8 项更新测试、5 项队列回归测试和真实桌面流程通过，源码与公共发布工作树均构建成功。桌面证据使用 4 个微型资产（入口、两卷与清单），没有启动安装器。

验收时另外查询了真实无鉴权 GitHub 公共 API：安装版当时仍处于上传草稿，所以公共列表为空，检查不会提示可下载。微型资产验证不应描述为真实大包网络下载验收。
