# 小安装包、组件管理与入门教学

用户决定：停止旧完整离线包上传，不再提供完整离线发行。默认小型 NSIS 安装器；必要运行环境与可选 AI 环境独立安装、缓存和复用。

## 实施

1. 停止旧分卷上传助手，撤下未发布的 2.1.1 草稿，保留本机验收文件。
2. Electron 组件管理器独立于 Python 后端。随安装器仅携带经过校验的 uv、项目桥接及其最小依赖；首次启动可在后端未就绪时完成基础安装。
3. 基础组件：固定 CPython/基础 Python 包、FFmpeg。官方源下载，固定版本与哈希；用户缓存独立于应用安装目录；安装后实际导入、工具功能检测，完成标记最后写入。
4. RAFT 组件：独立 PyTorch CUDA/torchvision 和官方权重。固定包锁与 SHA；不影响没有 RAFT 的基础链；安装完成后明确重启生效。
5. 原生 GPU 检测独立于 Torch，RAFT 缺失仅影响 RAFT。所有现有模型运行库仍使用原独立管理/本地发现机制。
6. 首次启动三步教学：准备组件、导入与重建、导出。可重开、可跳过教学；缺少必要组件不能进入正常工作台。设置提供组件管理入口。
7. 更新器与发布脚本改为单个小型 Setup EXE；删除默认分卷和离线包指引。构建 2.1.2，实际安装与真实无 Torch GPU 短验收，发布已校验附件。

## 验收

- 单任务安装、取消/失败/重试、缓存复用、锁文件/工具摘要、隔离与正确缺失提示测试。
- 实际安装器大小、包中没有 Torch/CUDA AI 库/RAFT 权重/完整 Python 环境。
- 实际首次安装基础组件、未安装 Torch 启动后端/WebSocket、加载素材、原生 GPU 信息、短 NR 预览。
- RAFT 环境导入与短真实 CUDA 测试；下载与已有缓存复用分别标注，不伪称所有大包已在线重新下载。
- 实际教学页导航、跳过与重开；完整后端和小包更新入口不依赖开发机路径。
- 性能不做无证据承诺；大组件第一次使用仍占网络和磁盘，程序更新不再次传输这些组件。
