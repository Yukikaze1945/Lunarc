# 可排序渲染链路

目标：用户添加、移除、拖动或用按钮排列 DLAA / DLSSNR / RTX VSR；预览与导出严格执行相同列表。既有设置迁移时保留原顺序，NR 单独使用的 HDR/SDR10 链路保持原样。

实现：共享阶段列表校验与尺寸规划；NR 前后分别串接设备资源阶段，VSR 在 NR 前时重建后续缩放、残差及融合尺寸；独立 DLAA 历史。自动发现本机 NGX 缓存和已安装/应用旁 VFX 运行库，手动覆盖放在高级中，缺失明确报错。VSR 1–4 档直接连接原生 QualityLevel。

验证：列表/尺寸/迁移/资源清理单元测试，前端构建与交互检查，真实 GPU 有序组合的短预览和导出，核对阶段调用顺序、尺寸、视频内容和音轨。保留 SDR8 原生模型限制，DLAA 零深度/抖动限制；不宣称驱动必含 VFX 运行库。不委派，不提交或推送。
