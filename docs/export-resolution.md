# 导出分辨率

导出设置中的分辨率决定最终文件的宽高。

- **渲染链输出**：直接采用整个渲染链处理后的尺寸。比如 VSR 输出 8K，导出的文件也是 8K。
- **素材分辨率**：采用输入素材的宽高。VSR 放大后会在导出前缩回这个尺寸。
- **指定分辨率**：可选 8K、5K、4K、1440p、1080p、720p，或填写自定义宽高。
- **倍率**：相对于输入素材计算，支持 ×2、×0.5 和自定义倍率。

最终尺寸与渲染链尺寸不同时，页面显示“导出缩放算法”。缩放发生在所有渲染阶段之后，包括 VFG 生成帧。尺寸相同时不执行缩放，也不显示算法选择。

GPU 导出支持最近邻、双线性、双三次和 Lanczos 2。缩小时，后三种扩大滤波范围以减少混叠。SDR 8-bit 保持 RGBA8；SDR 10-bit 和 HDR 使用有符号线性 FP16，滤波累加使用 FP32，随后由原有色彩桥转为 P010。HDR 色彩声明和静态元数据继续由原有编码及封装链路处理。

实际可编码尺寸还取决于显卡、编码器及显存。选择更高导出分辨率不会改变 VSR 卡片本身的目标分辨率。
