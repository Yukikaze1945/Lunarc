# 图片加载与导出

将 PNG、JPEG、BMP、WebP、TIFF、AVIF 或 HEIC／HEIF 图片拖入工作台，或通过“导入”选择。普通 8-bit 图片直接解码为 RGBA 并上传一次到 GPU，之后复用上传的图片和已有渲染链，不转成视频、不经过 YUV 4:2:0。

工作台与图片导出页均支持 Alt＋滚轮缩放（25%–800%）、左键拖动画面。放大后，不按 Alt 的滚轮上下移动图片；图片未超出画布时保留页面正常滚动。双击恢复适配。工作台保留完整原图和处理图，在前端完成缩放、移动与中央对比，查看位置不改变导出尺寸，也不重新运行模型。

图片可以使用 DLSSNR、DLAA、RTX VSR、IllustrationJaNai V3、AnimeSharp V4 和 TrueHDR，以及现有的多层 NR 处理。静态图片使用零运动输入，不计算帧间光流或时间稳定，不执行 VFG。播放进度与选区控件在图片模式下隐藏。

点击右上角“导出图片”，设置格式、保存位置和文件名：

| 格式 | 保存选项 |
| --- | --- |
| PNG | 无损编码，支持保留透明度 |
| JPEG | 质量 1–100；不透明，原图透明区域填充白色 |
| WebP | 质量 1–100；100 为无损编码，支持保留透明度 |
| AVIF | AV1 图片编码，质量 1–100，4:4:4，支持透明度；100 不标为 RGB 无损 |
| HEIC | HEVC 图片编码，质量 1–100，4:4:4，支持透明度；100 使用 RGB 无损模式 |

输出采用当前工作台的渲染参数和整条渲染链的输出尺寸。单张图片会重新以完整分辨率处理，不保存 JPEG 预览截图。必要的边缘补齐会在输出时裁掉；透明度从原图恢复，缩放时同步缩放透明度。

嵌入的 ICC 配置会在输入时转换为 sRGB；JPEG 的 EXIF 方向用于纠正图片方向。导出的普通图片写入 sRGB ICC 配置。启用 TrueHDR 时，最终 FP16 HDR 结果通过固定显示映射转为 sRGB SDR 图片，页面明确显示此行为，不将其标为 HDR 图片。

当前图片入口和这五个导出格式提供 8-bit SDR 图片输出。高位深图片入口暂未接入，明确拒绝，不自动降为 8-bit。动画图片仅处理第一帧。不是图片批量导出队列。禁止覆盖原图片；默认不覆盖已有目标文件，临时文件成功编码后才发布结果。

AVIF 使用 [Pillow AVIF 编码器](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#avif)，HEIC 使用 [pillow-heif](https://pillow-heif.readthedocs.io/en/stable/saving-images.html)。源码依赖与运行环境构建清单已包含 Pillow ≥11.3、pillow-heif 1.8.1。格式按钮按后端实际编码能力启用；缺少编码器时不通过改扩展名或换格式冒充成功。

源码版改动生效需要退出工作台后运行 `run_gui.bat`。安装版仍需要后续重新构建，本轮没有发布新的安装包。

## 图片放大模型与多层 VSR

图片模式的渲染顺序中可以添加两个模型磁贴，与 DLSSNR／DLAA／VSR 一样排序、停用和移除：

- IllustrationJaNai V3：4× DAT2，去噪／细节版本。作者发布了多种网络，本次磁贴明确使用 DAT2。
- AnimeSharp V4：2× RCAN 标准版。
- 默认整图、FP32 推理。分块 128／256／512 为可选项，带 32 像素输入边缘上下文；分块可能改变全图上下文与边缘结果，不自动启用或在显存不足时偷偷改用分块。
- 当前只接收 SDR 图片，请放在 TrueHDR 前。各模型按自身倍率放大；透明度在保存时从原图恢复。整图处理大图片仍可能超出可用显存。

磁贴提供官方来源下载和本地 `.safetensors`／`.pth` 导入，权重放在用户数据目录的 `image-models` 缓存。官方压缩包／文件验证固定 SHA-256 和长度；本地导入记录 SHA-256，加载时复验，且只用安全张量或 `weights_only=True` 加载。未安装、架构／倍率不匹配和损坏文件明确拒绝。下载完成或重新导入后刷新预览。

安装版先在组件管理安装 **AI 模型运行环境**（与 RAFT 共用 PyTorch／CUDA），再安装 **图片模型组件**。模型权重单独下载，不包含在安装包中。模型许可与 Lunarc 源码许可分别适用，请查看 [IllustrationJaNai 作者发布页](https://github.com/the-database/MangaJaNai/releases/tag/3.0.0) 和 [AnimeSharp V4 作者模型页](https://huggingface.co/Kim2091/2x-AnimeSharpV4)。

RTX VSR 可重复添加，每张磁贴独立保存模式、档位、强度、倍率／分辨率和开关。每层接收上一层的输出，显示与导出尺寸按顺序累计。旧预设中的单层 `vsr` 和全局 VSR 参数继续有效。

## 释放预览显存

工作台预览工具栏提供 **释放预览显存**。点击后暂停播放、等当前帧完成，释放预览链、解码与显示资源、RAFT 权重及 PyTorch 保留缓存；参数和磁盘上的模型文件不删除。释放后调整参数不会自动重载，点击 **恢复预览** 才重新加载。恢复后首次预览可能更慢。

显存紧张且更换模型、尺寸、来源或链路时，程序会先完整释放旧预览，再按原参数加载新预览；普通后处理调整继续热更新。导出期间不能用此按钮释放导出资源。预览保持暂停时也可明确导出图片，完成后释放这次操作加载的预览模型。

自动保护依据当时可读取的显存预算，不降低精度、分辨率或自动启用分块。重新加载时会拦截已知工作图像缓冲都放不下的请求；SDK 内部模型和瞬时工作区无法完整预估，保护不能保证所有组合都不再显存不足。资源关闭失败仍会停止新 GPU 操作并进入原有恢复流程。
