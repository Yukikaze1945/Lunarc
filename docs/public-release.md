# 测试记录

## 2.1.2

测试系统：Windows x64，NVIDIA GeForce RTX 5060 Ti（16 GB）。测试日期：2026-10-12。

| 项目 | 结果 |
| --- | --- |
| 安装程序 | NSIS 安装成功，146,387,590 字节，约 140 MB。 |
| 基础组件 | CPython 3.10.18、基础 Python 依赖和 FFmpeg 8.1.2 下载、安装及检查通过。 |
| 首次使用 | 安装按钮、三步教程、进入工作台和重新打开教程通过。 |
| 后端启动 | 使用组件目录中的 Python，在无效开发环境路径下隔离启动通过。 |
| GPU 检测 | 基础环境未安装 Torch 时，显卡检测和原生库加载通过。 |
| 队列 | WebSocket 连接与 init 消息通过。 |
| DLSSNR 预览 | 导入并使用外部 DLSSNR 310.8.0.0；1280×720 视频预览和连续播放通过。 |
| RAFT 安装 | PyTorch 2.10.0+cu128、torchvision 0.25.0+cu128 和模型安装通过。 |
| 下载续传 | PyTorch 主包从 2,216,011,845 字节处继续下载，最终大小及 SHA-256 匹配。 |
| RAFT 运行 | CUDA 上执行 128×192 帧对、2 次迭代，输出形状 `[1,2,128,192]`，数值有限。 |
| 重启 | 已安装的 RAFT 组件在重启后启用，CUDA 运算和权重检查通过。 |
| 相关自动测试 | Node 22 项、Python 21 项通过。 |
| 发布附件 | 4 个附件的大小和 SHA-256 与本地文件一致，公开下载链接可访问。 |
| 更新检查 | 通过公开 GitHub API 识别 2.1.2，并核对安装说明及校验清单。 |

首次组件下载来自对应官方源；后续桌面测试使用已校验的下载缓存。

### 测试范围

上述结果来自已有 NVIDIA 驱动的一台 Windows 机器。没有进行多机兼容性测试、完整 HDR/VFG 导出回归、画质评测或速度基准测试。相关自动测试不等同于全量测试。Performance = NOT_CHARACTERIZED。

公开下载检查读取了安装程序的前 1024 字节；完整文件摘要通过 GitHub 资产信息与本地文件核对。

### 修复记录

- RAFT 本地 wheel 安装改为仅接受对应 Windows 主包的精确 SHA-256，解决多平台摘要列表造成的安装失败。
- 教程和运行库检查脚本修正了 API 返回值、参数同步与目录联接路径的判断。表中结果取自修正后的通过记录。
