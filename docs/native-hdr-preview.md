# GPU 视频预览

Windows 工作台视频预览统一使用原生显示面板，支持 SDR 8-bit、SDR 10-bit 和 HDR。Electron 管理布局和按钮；D3D12 面板显示两侧 GPU 画面，使用 FP16 / 线性 scRGB 交换链。当前文件对比页仍使用此前的硬件解码、GPU 缩放和 JPEG 通道。

## 使用

- 完全退出旧程序和后端，再运行根目录的 `run_gui.bat`。
- 在工作台选择“对比”，拖动中央金色分隔线。滑块直接重绘保留的 GPU 画面，不重新解码、运行模型或编码 JPEG。
- 支持原图、增强、中央对比和双画面；放大后可右键拖动。窗口布局按物理像素同步，处理高 DPI、缩放、全屏和页面切换。
- 工具栏统一显示“GPU 预览”。Windows HDR 状态和 SDR 白色亮度由显示系统读取，移动窗口或改变显示状态后更新；显示器未开启 HDR 时，HDR 内容使用固定 SDR 映射。
- 视频预览没有普通图像模式的切换按钮。窗口连接完成后才发送视频预览请求；原生初始化或 GPU 显示错误会直接报告。浏览器、静态图片和光流诊断继续使用已有图像路径。

## 数据流与资源

原始源画面与最终处理结果在生产者资源失效前复制到显示面板自己的 GPU 缓冲。后续解码、模型处理不会覆盖正在对比的图像。显示和处理使用各自的命令队列及完成栅栏，资源释放先于处理设备和 CUDA 上下文释放。

两侧在同一次 GPU 绘制中合成。SDR 内容先解释为线性 RGB；在 HDR 桌面上按 Windows 的 SDR 白色亮度呈现。HDR 内容保留线性 scRGB 的高亮和宽色域值，不走原来的 SDR 肩部映射。系统关闭 HDR 时才对 HDR 内容做固定 SDR 映射。

WebSocket 只传帧号、设置版本和诊断，保留旧请求失效检查及确认节奏，不传图片。拖动滑块、切换原图/增强、缩放和平移直接重绘，不请求新的处理帧。离开工作台会销毁显示窗口及显示缓冲。

显示接口参考 [微软 FP16/scRGB 文档](https://learn.microsoft.com/zh-cn/windows/win32/direct3darticles/high-dynamic-range)。

## 本机检查

SDR 8-bit 的中性后处理保留旧宿主纹理描述，它没有图像宽高；显示入口已补上处理帧的完整尺寸。真实 SDR8 NR 预览显示到 640×360 面板后，101 次中央滑块重绘仍只上传 1 对画面，已测显示图像回读为 0。该轮同步拖动调用平均约 0.45 ms、最大约 1.45 ms，包含绘制完成等待和 Present 调用，不代表屏幕实际帧率。证据为 `build/preview-playback-fix/native-sdr-proof.json`。

启动会话修复：显示面板接口和渲染入口通过同一个受锁保护的工厂取得预览引擎，避免并发创建两个引擎。进入旧图像宿主路径时，在 GPU 所有者线程关闭设备预览会话后才打开宿主会话。并发工厂检查及真实 GPU 的“设备→图像宿主→设备”短检查通过，防止 `host already active`；已出现该错误的旧进程需完全退出后重启。

导出会话保护：原生请求同样遵守导出占用状态，且在取得会话锁后再次检查。导出宿主标记独立所有权，预览不能关闭或重建它；界面在导出期间显示“正在导出，预览已暂停”。光流/编码初始化失败也会清理导出所有权。13 项相关回归通过；真实 SDR10 + NVOF + HEVC Main10 的三帧导出中，在每帧间请求原生预览，三次请求都被阻止，导出完成且宿主正常释放。证据为 `build/preview-playback-fix/export-ownership-proof.json`。

- 原生 C++ 在 `/W4 /WX` 下编译链接通过；显示 shader 实际执行通过。
- 真实 Electron 跨进程子窗口嵌入，在当前高 DPI 和已启用 HDR 的显示器上通过。
- 一对 320×192 FP16 画面显示到 640×360 面板，101 次中央滑块重绘后，上传画面对仍为 1 对。该轮同步拖动调用平均约 0.37 ms、最大约 2.16 ms，包含 GPU 绘制完成等待和 Present 调用，不代表显示器实际刷新率。
- 真实 SDR10→TrueHDR 管线的原生显示通过：已测显示图像回读为 0；参数热更新复用会话；关闭原生模式后成功恢复 320×192 图像输出；关闭后没有遗留测试子窗口。
- 23 项布局、原生报文、预览调度、缓存和生命周期检查通过；前端构建通过。

证据在忽略目录 `build/preview-playback-fix/native-proof.json` 和 `native-electron-result.json`。不根据小尺寸检查承诺 4K 120 fps 推理或屏幕刷新。显示边界没有主机图片传输，处理阶段仍可能有标量读回，不能声称总主机流量为零。该改动已纳入 1.0.0 Beta 安装版。
