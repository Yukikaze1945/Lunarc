# 预设与选区预渲染

## 预设

重建工作台右侧的「预设」位于渲染顺序上方。选择已保存的预设即可应用；点击「保存预设」给当前参数命名。同名保存会替换原预设。

「预设管理」只列出保存的预设。展开一行，可以看到相对默认值改变的参数、默认值、保存值和改动幅度。例如 NR 强度从 1 改为 0.7，显示 −0.3（−30%）；默认值为零时只显示差值。风格、开关和渲染顺序显示选项变化，不计算无意义的百分比。第二、第三层的改动分别列出。

参数修改后，工作台选择框显示「当前参数」，避免误认为仍与所选预设完全一致。JSON 导入、导出兼容原有本机预设格式。

## 折叠

渲染顺序、带参数的阶段卡片、DLSSNR 参数及高级参数分组，可通过右侧的「− / ＋」收起和展开。折叠不移除阶段，也不修改参数。排序仍由拖动手柄及上下按钮控制。

## 底栏

- **显存**：NVIDIA GPU 0 的整卡占用与总容量，包含其他程序，每约 5 秒采样。不是 PyTorch 缓存或 Lunarc 独占用量。查询失败显示「—」。
- **渲染 FPS**：最近完成的一帧从解码到预览处理的耗时换算值。初始化、定位和缓存都会影响它，不能作为稳定性能基准。
- **显示 FPS**：播放时实际呈现的帧率，不使用素材标称帧率代替。
- **阶段延迟**：最近的原生调用墙钟测量。NR 显示各层模型推理合计；光流、融合与显示另计。复用模型输出时显示「缓存」。VFG 在实时预览中跳过，显示「仅导出」。这些不是 GPU 时间戳，不能直接相加当成整帧延迟。

## 选择片段

1. 载入视频，勾选时间轴下方的「选区导出」。首次选择从当前帧开始，默认覆盖约两秒。
2. 拖动两个边界，或输入起始、结束帧。界面帧号从 1 开始，结束帧包含在选区内；后端使用从 0 开始、结束不含的范围。
3. 「导出与队列」中的新任务只处理当前选区。关闭「选区导出」恢复全片导出。

选区使用 GPU 导出，编码格式按现有界面规则同步约束。起点重置时域历史；边界附近可能与从全片起点连续处理的对应画面不同。当前按帧选择要求恒定帧率、连续呈现时间戳；遇到可变帧率或缺帧会明确拒绝，避免导出错误帧号。

## 预渲染与绿条

「预渲染选区」使用当前渲染链和「导出与队列」中的编码设置，生成真正的编码片段，不用实时预览图片代替。预渲染开始时暂停实时播放，复用已有的单 GPU 导出队列。空闲时只启动预渲染任务，不启动其他待导出任务；取消、失败和重试在队列里操作。预渲染不会执行睡眠或关机完成动作。

成功后时间轴出现绿条；点击绿条或「回看结果」，在视频对比页播放该片段。原片按选区起点对齐，不与全片零秒位置比较。HDR 回看沿用对比页的 SDR 显示映射，不代表经过校准的 HDR 显示。

绿条只对应已完成、文件存在且仍匹配当前素材与参数的缓存。素材修改、渲染参数、编码设置或关键处理模块变化，会让旧缓存不再标绿。缓存保存在 `%LOCALAPPDATA%\Lunarc\render-cache`，完成记录可在重启后读取；移除完成的队列任务不会删除缓存。此版本未设置自动磁盘容量上限，可在应用关闭后手动清理该目录。

片段视频时间从零开始。音轨复制会丢弃选区前的音频包，保留选区内的原包内容；复制音轨的边界精度受音频包长度限制。字幕包的起点和时长被裁切，章节由 FFmpeg 按输入范围映射，可能保留边界上的零长度章节。原始视频不被重封装写回。

## 本轮检查

- 前端构建；隔离浏览器中的预设保存、参数差异、阶段折叠、选区提交、未完成不标绿、完成标绿及参数改变后的失效检查。
- 范围校验、GOP 前滚丢弃、呈现时间戳归零、可变帧率拒绝、缓存持久化及失效、单队列恢复的针对性检查。
- 本机 SDR 8-bit 和 BT.709 SDR 10-bit 各一次真实 NVDEC → DLSSNR → NVENC 的六帧选区处理，连续对比回看与原片对齐。重封装修正后复查原始已渲染画面，不重复模型推理；音轨原包哈希保留，首视频 PTS 为零。
- 跨选区起点、终点的 SRT 字幕离线检查：包内容保留，显示区间裁切，输出时长保持 0.2 秒。

证据保存在本机忽略目录 `build/segment-preview-check` 与对应检查日志中。这是短功能检查，没有验证所有字幕编码，也没有测量跨机器性能。`Performance=NOT_CHARACTERIZED`。
