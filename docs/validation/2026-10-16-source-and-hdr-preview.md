# 原素材显示与 HDR 图片预览

## 本轮改动

- 手动“开启渲染”只控制效果链。未开启时，图片读取原文件，视频通过独立 `/api/source/frame` 读取 CPU 解码帧；拖动选区、逐帧定位和停止渲染后仍可显示原素材，不恢复 GPU 模型会话。
- 原片请求带路径并与当前素材核对；前端取消过期请求、校验素材对象归属，避免切片后显示上一份素材。最后一张视频原片 JPEG 缓存在主机内存。
- HDR 视频的原片缩略图使用已有的固定 HDR→SDR 显示映射，CPU 解码缩略图尺寸限制在 1920 以内。不将 PQ 码值直接当作 SDR 显示。
- 桌面版启用 TrueHDR 的图片也通过已有原生 FP16/scRGB 显示器呈现。图像不经 JPEG 往返；图片发送原生视图请求时保留所选视图，不再强制切成给浏览器使用的双画面布局。
- 原生图片路径不再对空的 BGR 显示图做裁剪；改为调整输入描述符的逻辑宽高，保留 GPU pitch，去除对齐填充。
- HDR 标识根据原生报告的 `hdr_active` 显示 HDR 或 SDR 映射；未开启效果时，不因链路配置了 TrueHDR 就把普通原素材标成 HDR→SDR。
- 原生 HDR 图片目前沿用现有原生播放器的缩放菜单、右键平移和分割线拖动；普通图片画布仍使用 Alt+滚轮、左键拖动。

用户正在运行 GPU 任务。本轮没有启动后端、GPU 预览、原生窗口、浏览器测试或任何导出测试，也没有替换 DLL 或安装包。
