日期：2026-10-17。范围为本机源码版本；没有发布安装包或重启现有后端。

## 实现边界

- stdio 适配器通过已认证的回环 HTTP 接口调用现有服务，不加载模型、不创建第二个 GPU 后端。
- 工作台和 MCP 共用后端预设；旧浏览器预设迁移前保留备份，同名项不覆盖。删除针对指定名称，避免误删后来新增的预设。
- 每个视频任务保存独立参数及请求标识。同一请求标识和参数重复提交返回已有任务，冲突参数拒绝。
- MCP 队列仅自动启动自身提交的任务，并等待已有 GPU 队列所有者退出。取消指定待处理任务不取消其他活动任务。
- 等待在适配器内部完成；超时不取消任务，等待连接错误保留任务和请求标识。图片也使用独立设置，避免继承后来变更的界面参数。
- 损坏的预设档案保留原文件并明确报错，禁止用空档案覆盖。
