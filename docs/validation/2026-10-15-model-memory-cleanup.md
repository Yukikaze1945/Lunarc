# 模型资源清理补缺

- 已有普通预览重建按先关闭旧链、再打开新链执行。DLAA 参数热切换则保留共享 NGX core；RAFT 权重缓存也有意跨预览重建复用。不能把每次接近显存上限的失败都归结为新旧模型同时打开。
- 修复 OutputEffect、EffectSeries 和图片模型的关闭路径：单个 SDK／资源关闭出错时，继续按依赖顺序尝试剩余资源，最终汇总错误；成功关闭和已尝试的句柄不重复调用。原生错误仍上报熔断，不视为已恢复。
- 图片模型 FP32 输出的 clamp、乘 255、round 改成复用输出存储；分块结果复制后及时删除 patch。没有修改精度、模型、分块设置和数学操作顺序。
- app-local Torch CPU 检查覆盖 786432 个通道值，新旧 8-bit 输出逐值相同，FP32 存储地址不变。证据 build/image-memory-gate/quantization.json。此项不是 GPU 峰值显存实测。
- 强制清除 RAFT／SDK 缓存、手动释放预览按钮和低显存自动冷启动尚未实现，因首次加载延迟会变化，按用户此前要求等待确认。
