# 内置 HTTP MCP 与工具说明

此修改取代初版以 stdio 为默认连接方式的设计。默认地址为 `http://127.0.0.1:18923/mcp`，复用软件后端进程、GPU 所有者和队列；客户端不启动 Python 或 uv。

复制提示词与 NVIDIA 示例保持相同形式：两句话说明服务器名称、Streamable HTTP 地址以及无法直接配置时的手动配置兜底。没有 JSON、安装路径或会话凭据。

设置面板将「连接详情」替换为「MCP 工具」，展开显示全部 13 项工具的用途，支持四种语言。

## 实现

- 使用官方 MCP Python SDK 2.0.0 的 Streamable HTTP 传输，JSON 响应、无状态会话，生命周期由软件后端管理。该固定版本适用于组件管理器的 CPython 3.10.18。
- HTTP 工具通过进程内 ASGI 调用已有认证的自动化路由。既不创建新渲染服务，也不向客户端交出后端会话凭据。
- `/mcp` 仅接受真实回环连接，并验证 Host 与 Origin。无令牌的浏览器来源请求拒绝；已有 REST 和权限设置继续要求会话令牌。
- 权限开关在 HTTP 入口与自动化路由均生效，默认关闭。关闭后新请求拒绝，已提交任务继续运行。
- 基础运行组件增加 SDK 和 HTTP 客户端，更新带哈希锁文件与组件就绪检查；不增加 PyTorch/CUDA 依赖。
- 原 stdio CLI 保留给只支持该传输的客户端，已退出默认提示词及界面。

## 证据

- MCP、自动化、权限和运行环境检查：42 passed。
- 在独立随机回环端口运行真实 HTTP 服务，官方客户端无令牌完成初始化、列出 13 个工具、读取共享预设与状态、参数校验和明确错误返回；关闭开关后 HTTP 403。没有启动用户后端生命周期或 GPU 渲染。
- ASGI 安全检查验证非回环对端、DNS 重绑定 Host、外部/本机浏览器来源均被拒绝；REST 与权限设置没有扩大令牌豁免。
- 独立浏览器面板检查通过：简短提示词复制、13 项工具说明、控制开关及保存失败回退。所有后端响应模拟。
- 语言检查 7 passed；组件管理检查 7 passed；前端构建通过。
- 用独立 uv 环境中的 CPython 3.10.18 实际导入 SDK 2.0.0 并构造 HTTP MCP 应用成功。没有更改正在运行的 GPU 环境。

未发布安装包，未重启用户软件。源码运行环境需安装更新后的基础依赖；组件版通过更新的基础锁文件安装 SDK。

协议实现参考 [官方 Python SDK](https://github.com/modelcontextprotocol/python-sdk)。使用说明见 [MCP 自动化接口](../mcp.md)。
