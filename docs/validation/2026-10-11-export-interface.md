# 导出界面、队列恢复与素材拖入验收

日期：2026-10-11

## 界面与格式约束

- 删除整个设备链路/命令预览栏及其能力说明、警告列表、复制命令按钮。
- 基础设置使用完整编辑宽度；高级 NVENC 参数按需展开。保留瑞士风格的分隔线、深色背景和黄色操作按钮。
- 所有设置分类共用底部「加入队列」按钮；仅实际阻断条件显示一条内联原因。
- 编码器、容器、像素格式、Profile、色彩、分辨率、WebM 音频、B 帧参考及附件复制直接约束控件。恢复草稿、切换源或应用预设也先统一格式，再生成队列请求。
- HDR10 / SDR10 当前入口仍为 HEVC Main10、P010、MKV，保留源色彩。GPU 全幅输出及 VSR 的现有目标尺寸规则保持原样；本次没有新增编码器或封装器。
- 音轨、字幕、章节、metadata 和 MKV 附件继续交给现有 remux；删除的是说明栏，不是这些功能。服务端验证保留。

## 队列恢复

- 工作线程在队列锁内逐个领取当前列表中的 pending 任务，不再遍历删除前的旧列表。
- 未运行的失败、取消、完成或待办任务可删除；运行中的任务须先停止，结束后删除。后端也拒绝直接删除运行中的任务（HTTP 409）。
- UI 通知回调异常不会中断导出或留下永久 running 行。删除/加入事件携带完整队列状态；界面定期重新同步，并忽略已删除行的迟到进度通知。
- 回归测试覆盖运行时删除后续任务、加入新任务、当前导出失败、再次启动以及通知异常。已结束任务没有隐式重跑。

## 素材拖入

- 应用任意区域支持本地视频/图片拖入，复用已有加载接口并进入工作台。
- Electron preload 通过 webUtils.getPathForFile 获取真实文件路径；不依赖废弃的 File.path。
- 不干扰渲染阶段排序的内部拖动；多文件取首个支持且有真实路径的素材。
- 加载请求串行，跳过过期请求；新素材打不开时保留此前素材和解码器。
- 普通 8-bit 单层 NR 静态图片预览使用既有图片解码与主机上传入口，避免交给 NVDEC 视频解码器。本次没有扩展 HDR/多层图片处理或新增图片输出格式。
