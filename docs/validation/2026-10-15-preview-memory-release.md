# 预览显存释放与切换保护

- 工具栏新增释放／恢复按钮。服务端暂停标志阻止排队的 refresh、seek、重连与帧接口重新加载模型，多客户端共享暂停状态。
- API 先暂停并使旧帧失效，再等全局 render gate 与生命周期锁。不会取消尚在执行的 CUDA／NGX 工作；HTTP 协程取消时也不提早交还 GPU gate。
- 资源在 GPUPreview 所属线程关闭，再在 Torch primary context 内删除共享 RAFT 权重、回收循环引用、同步并释放 allocator 缓存。模型文件和设置保留。
- 更换模型、来源或链路时，DXGI 剩余预算低于 max(512 MiB, 15% 预算)，或已有 Torch CUDA 设备的可用内存低于 1 GiB，跳过热重建并完整卸载。普通后处理参数不触发。
- 不为测显存新建 CUDA primary context；CUDA 查询只使用已初始化的 Torch。未知预算不当作零显存。
- 冷启动检查使用至少 512 MiB 余量及已知图片工作缓冲下界，不包含所有模型权重、激活和 SDK 内部峰值，不保证所有请求都能放下。不自动降精度、分辨率或启用分块。
- VSR 关闭立即检查原生错误，避免保留句柄的失败被当成成功。关闭失败的地址不重复调用；资源释放失败进入现有熔断恢复。
- 暂停预览时仍可明确导出图片，完成后释放本次加载的预览资源；正在释放时不能同时发起图片导出。视频导出持有资源时拒绝预览释放。
