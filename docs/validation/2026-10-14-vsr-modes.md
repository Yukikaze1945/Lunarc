## 实际 GPU 检查

`tests/helpers/vsr_modes_gpu_gate.py` 使用 640×360 合成 CUDA 输入，放大模式输出 1280×720，降噪/去模糊输出 640×360；每个模式处理两帧。

- 官方全部 19 档 × RGBA8/RGB10A2 = 38 个组合成功 Create/Set/Load/Run。
- SDK getter 回报的 QualityLevel 全部与请求一致；自定义 Strength=0.6 回报约 0.60000002，符合 FP32 精度。
- 诊断读取确认输出非全零；这些读回发生在测试工具，不计作生产图片零传输证据。
- Bicubic 同时覆盖旧 open/open2 入口；自定义 Strength 覆盖新增 open3 入口。

`tests/helpers/vsr_modes_preview_gate.py`：

- SDR8 六个模式家族各两帧预览；SDR10、HDR 分别检查高码率、降噪和 Streaming 各两帧。
- SDR8 标准→高码率→Streaming 都保持 generation=1；切到降噪变为 generation=2，再切去模糊保持 2，切到 Bicubic 恢复 2×并变为 3。
- 所有模式切换的 decoder handle 与 CUDA context 保持一致；实际效果计数器证明所选模式被执行，输出尺寸正确。
- SDR10/HDR 降噪各完成 3 帧 AV1 10-bit 导出：1280×720 / BT.709 与 1920×1080 / BT.2020 PQ，保持输入尺寸，编码入口图片主机传输计数为 0。
- 合成 360p SDR10 测试素材缺少必要颜色声明被正常拒绝，后续使用已有 HD SDR10 与 HDR 验证素材。HD SDR10 的既有 BT.709 缺失字段解析策略保留在诊断，不称为原文件完整声明。本轮没有放宽颜色准入规则。
